TUPSHADERS / GRAPHICS (F = desktop GUI)
================================================================================
Master:
- Master enable / disable
- Adaptive quality / performance budgets
- PC Shader GUI (desktop IMGUI, press F by default)
- Cycle preset from pad Shader Settings
- TUPshaders master toggle from pad
- Sync builtin presets to Plugins/.../TUPshaders/Presets on launch
- User preset save / load / import / export JSON

Builtin presets:
- Competitive
- Balanced
- Cinematic
- Ultra
- GEffects Style
- Neon Psychedelic
- ReShade Style
- Natural
- Realistic (IRL-style filmic grade)
- Vibrant
- Low-End PC

Effect categories / knobs:
- Color grading (vibrance, saturation, contrast, gamma, temperature, tint,
  lift, gain, tonemap, LUT strength)
- Bloom (threshold, soft knee, radius, dirt, downsample)
- CAS sharpening (adaptive)
- Ambient lighting + shadow boost
- Sky improvements
- Fog (distance / height density)
- Lens effects (vignette, grain, dirt, flare, chromatic aberration)
- Ray Look: SSAO (contact shadows), SSR (screen reflections), god rays
- Neon / GEffects: neon magenta look + intensity + pixel dither controls
- IRL look flag (Realistic)
- Shadows / lighting / performance / debug readouts

Runtime paths:
- URP Volume driver (Bloom, Color Adjustments, Tonemapping, White Balance,
  Vignette, Chromatic Aberration)
- CodeLookComposer (RenderSettings ambient / fog / reflections / shadows)
- ScreenGradeOverlay (PC fallback soft grade when native bridge inactive)
- RenderAgent camera discovery + URP post force on Main / Shoulder / VR cams
- ThatUtilsPad.RenderBridge.dll — native D3D11 Present hook (ReShade-class
  IRL pack: aerial/height fog, grass revive, underside bump, micro-detail,
  denoise vs lost/blocky pixels, full D3D state restore, quality tiers)
  + "ReShade Bridge" GUI; Realistic preset enables fx.look.irl + grass/bump
  Soft Unity material color polish on grass/leaf/tree names (not texture dump)

NOTES / LIMITS:
- Hardware DXR ray tracing is NOT available — Gorilla Tag uses D3D11.
  Public URP “ray tracing” / ReShade RTGI-style work is screen-space marching.
- Build native bridge with VS 2022 C++ (see ThatUtilsPad.RenderBridge/README.md)
  or run build.bat (builds C# + native when MSBuild is present).
- Place ThatUtilsPad.RenderBridge.dll next to ThatUtilsPad.dll in plugins.

================================================================================
MISC / TECH

- BepInEx plugin (netstandard2.1)
- Embedded TUPshaders (no separate shader AssetBundle required for current path)

  Or: dotnet build ThatUtilsPad\ThatUtilsPad.csproj -c Release
